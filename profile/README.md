# WorthMyTime

**Budujemy nowoczesną aplikację finansową z pomocą sztucznej inteligencji. Jesteśmy otwartym projektem zespołowym, w którym rozwijasz umiejętności i pracujesz nad realnym produktem, a potem możesz wpisać go do portfolio.**

WorthMyTime pomaga świadomie zarządzać pieniędzmi. Zaczęło się od pytania *ile godzin Twojej pracy kosztuje ten zakup?*, a dziś rośnie w pełną aplikację finansową: budżet, wydatki, zobowiązania, cele i ostrzeżenia, które pomagają podejmować lepsze decyzje, zanim wydasz pieniądze.

## Dlaczego warto dołączyć

- **Realny produkt, nie ćwiczenie:** logika finansowa, konta i bezpieczeństwo, migracje bazy, CI i wydania
- **Praca zespołowa od pierwszego dnia:** issue, branch, pull request, code review, wydania przez `dev` → `stage` → `main`
- **Wpis do portfolio, który da się sprawdzić:** repozytoria są publiczne, a Twoje commity i pull requesty są podpisane Twoim kontem GitHub
- **AI jako narzędzie pracy:** uczymy się pracować z asystentami kodowania odpowiedzialnie i skutecznie
- **Wpływ na kierunek:** mały zespół, więc Twoje pomysły realnie kształtują produkt
